# 📸 Imagens — Clínica Reali

Substitua os placeholders abaixo pelas imagens reais antes do deploy em produção.

## Imagens necessárias

| Arquivo | Dimensão sugerida | Descrição |
|---------|------------------|-----------|
| `hero-clinica.webp` | 1920×1080 | Fachada ou interior premium da clínica |
| `hero-mobile.webp` | 768×1024 | Versão mobile da imagem hero |
| `sobre-nos.webp` | 800×600 | Equipe da clínica em ambiente profissional |
| `implante-dentario.webp` | 600×400 | Procedimento de implante ou sorriso pós-implante |
| `harmonizacao.webp` | 600×400 | Harmonização orofacial / resultado |
| `urgencia.webp` | 600×400 | Dentista em atendimento de urgência |
| `odontologia-geral.webp` | 600×400 | Consulta odontológica geral |
| `depoimento-1.webp` | 80×80 | Foto do paciente 1 (avatar) |
| `depoimento-2.webp` | 80×80 | Foto do paciente 2 (avatar) |
| `depoimento-3.webp` | 80×80 | Foto do paciente 3 (avatar) |
| `og-image.webp` | 1200×630 | Imagem para compartilhamento em redes sociais |

## Dicas de qualidade
- Use formato **WebP** para melhor performance
- Comprima com ferramentas como [Squoosh](https://squoosh.app) ou TinyPNG
- Inclua alt text descritivo (já configurado nos componentes)
